Core Conceptsextends Keyword: Used by a subclass to establish inheritance from a superclass.super Keyword: Refers to the immediate parent class object. Used to invoke parent constructors (super()) or access parent methods/fields overridden in the child class.Method Overriding: Defining a method in the child class with the exact same name, return type, and parameter list as a method in the parent class to supply child-specific behavior.Types of Inheritance in JavaTypeDescriptionSupported via Classes?SingleOne class inherits from a single parent class (A <- B).YesMultilevelA class inherits from a parent, which itself inherits from another (A <- B <- C).YesHierarchicalMultiple classes inherit from a single parent class (A <- B and A <- C).YesMultipleA single class inherits from multiple parent classes directly.No (Avoids ambiguity/diamond problem; achieved via interfaces instead).HybridCombination of two or more types of inheritance.No (Only possible using interfaces).Important Rules & Limitationsprivate Members are Not Inherited: Private fields and methods of a parent class cannot be directly accessed by the child class (though they can be accessed via non-private getters/setters).final Classes Cannot Be Extended: Marking a class final prevents any other class from inheriting it (e.g., public final class Vehicle).final Methods Cannot Be Overridden: Prevents child classes from changing specific parent implementation logic.The Object Class Root: Every class in Java implicitly inherits from java.lang.Object if no other superclass is specified.
